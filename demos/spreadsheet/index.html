      Keyboard shortcuts

      Edit cell Enter / F2 or start typing
      Confirm and move Enter Tab Shift+either
      Cancel editing Esc
      Extend selection Shift+arrows, Ctrl+Shift+arrows
      Jump to data edge Ctrl+arrows
      Select column / row / all Ctrl+Space / Shift+Space / Ctrl+A
      Copy, cut, paste Ctrl+C X V, values only Ctrl+Shift+V
      Fill down / right Ctrl+D / Ctrl+R
      Bold, italic, underline Ctrl+B I U
      Undo / redo Ctrl+Z / Ctrl+Y
      Sum Alt+=
      Find and replace Ctrl+F / Ctrl+H
      Cell menu Shift+F10
