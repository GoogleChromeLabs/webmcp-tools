# WebMCP Demos

This folder holds the [WebMCP](https://webmachinelearning.github.io/webmcp/) demos. Each demo has its own README, and the [main README](../README.md#demos) lists them all. The requirements below apply to every demo.

## Requirements

WebMCP is in early preview. To try the demos with an AI agent, you need:

- Chrome 155.x or later
- A WebMCP agent, such as the [Model Context Tool Inspector](https://chromewebstore.google.com/detail/model-context-tool-inspec/gbpdfapgefenggkahomfgkhfehlcenpd) or the [WebMCP extension](https://github.com/GoogleChromeLabs/webmcp-extension)

To run a demo locally, or in another Chromium-based browser such as Edge, also turn on the WebMCP flag at `chrome://flags/#enable-webmcp-testing` (`edge://flags/#enable-webmcp-testing` in Edge) and relaunch the browser. WebMCP needs a secure context, so open local demos on `localhost`.
